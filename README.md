## Contribution
Any changes to upstream c# code should be marked with //NS or //Noosphere on the exact line or any changes should be between //NS start and //NS end. Removals should be commented out and have a comment explaining why.

This repo hardforks upstream yaml and resources so that can be changed and removed without marking changes.
